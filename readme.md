## Installation

Install Python and the required libraries first. You can use this command:

```bash
pip install pandas numpy matplotlib seaborn scikit-learn jupyter
```

## How to Run

1. Open the project folder in VS Code or Jupyter Notebook.
2. Go to the `notebooks` folder.
3. Open the notebook you want to run.
4. Run the cells one by one from top to bottom.

If you are using terminal, you can start Jupyter with:

```bash
jupyter notebook
```
